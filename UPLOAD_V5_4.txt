findol v5.4 업로드 방법

1. 이 압축파일을 컴퓨터에서 풉니다.
2. GitHub findol-law-portal 첫 화면에서 Add file → Upload files를 누릅니다.
3. 압축을 푼 곳의 backend 폴더와 frontend 폴더를 함께 끌어놓습니다.
4. 업로드 목록에 아래 경로가 보이는지 확인합니다.

backend/app/data/substance_map.json
backend/app/data/search_dictionary.csv
backend/app/search_engine.py
backend/app/main.py
frontend/index.html
frontend/script.js
frontend/style.css

5. Commit changes를 누릅니다.
6. Render 배포가 Live가 되면 Ctrl+F5로 새로고침합니다.
7. 검색창에서 '인산 85%' 또는 '차야염소산나트륨'을 시험합니다.
