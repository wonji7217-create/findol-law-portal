# 환경·안전 법령 검색 포털 (백엔드 — 1~2단계 완료)

화학물질관리법 중심으로 키워드 검색 시 관련 법령·고시·훈령을 보여주는
검색 포털의 1단계(백엔드 API) 스캐폴드입니다.

브리핑봇(crawler.py, gmail_sender.py)과는 완전히 별도의 프로젝트입니다.

## 구조
```
law-portal/
├── backend/
│   ├── app/
│   │   ├── main.py       # FastAPI 앱, /api/search 엔드포인트
│   │   └── law_api.py    # 법제처 Open API 연동 클라이언트
│   ├── requirements.txt
│   └── .env              # LAW_API_OC (법제처 인증키)
└── frontend/              # 2단계에서 채울 예정 (React)
```

## 실행 방법 (로컬 PC 기준)

1. 가상환경 생성 및 패키지 설치
```bash
cd law-portal/backend
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

2. 서버 실행
```bash
uvicorn app.main:app --reload --port 8000
```

3. 브라우저 또는 curl로 테스트
```
http://localhost:8000/api/search?q=안전진단
```

## ✅ 2단계 완료: 데이터 축적 (DB 저장 · 타임라인)

검색할 때마다(`/api/search`) 결과가 자동으로 SQLite(`law_portal.db`)에 쌓입니다.
같은 항목이 내용 변경 없이 다시 검색되면 중복 저장하지 않고, **내용이 달라졌을 때만**
새 스냅샷을 추가해서 자연스럽게 개정 이력이 쌓이는 구조예요.

### 새로 생긴 API

- `GET /api/timeline?keyword=화학물질` — 지금까지 수집된 법령/고시를 최근 수집일 순으로 조회
- `GET /api/history/law/{external_id}` — 법령 하나의 전체 변경 이력(개정 흐름)을 시간순으로 조회
- `GET /api/history/admin_rule/{external_id}` — 고시/훈령 하나의 변경 이력 조회

`external_id`는 `/api/search` 결과의 `id` 필드 값입니다.

### 참고
- DB 파일(`law_portal.db`)은 `backend/` 폴더에 자동 생성됩니다. 로컬 테스트 논리
  검증은 완료했지만(중복 방지 · 개정 감지 · 이력 누적 정상 작동 확인), 실제
  law.go.kr 응답을 반복 수집하면서 개정 이력이 진짜로 쌓이는지는 며칠~몇 주
  간격으로 같은 키워드를 검색해봐야 눈으로 확인 가능해요.
- 지금은 "검색할 때마다 저장"하는 방식이라 자동으로 매일 수집되진 않아요.
  주기적 자동 수집(스케줄러)이 필요하시면 다음 단계에서 붙여드릴게요.

## ✅ 3단계 완료: 화면 (프론트엔드)

별도 React 빌드 도구 없이, **백엔드(FastAPI) 서버가 화면까지 같이 서빙**하도록
만들었어요 — 서버 하나만 켜면 API도, 화면도 동시에 뜹니다 (CORS 설정도 신경 쓸
필요 없음).

### 실행 방법 (1~3단계 통합, 이제 이것만 하면 됩니다)

```
cd law-portal/backend
python -m uvicorn app.main:app --port 8000
```

서버 켜진 상태에서 브라우저로:
```
http://localhost:8000/
```
접속하면 검색창 화면이 바로 뜹니다. (`--reload` 옵션은 DB 파일 변경 때문에
계속 재시작될 수 있어 뺐어요. 코드를 수정하면 서버를 껐다 다시 켜주세요.)

### 화면 구성
- **검색 탭**: 키워드 검색 → 법령 / 고시·훈령 결과를 카드 형태로 표시
- **타임라인 탭**: 지금까지 검색으로 쌓인 데이터를 최신순으로 표시, 키워드 필터 가능
- 결과 카드를 클릭하면 국가법령정보센터 원문 페이지로 이동

디자인은 화학물질 안전표지(경고 스트라이프)에서 모티프를 가져와서
industrial-safety 톤으로 잡았어요. 로고나 SEEDPARTONE 브랜드 색상 반영은
다음에 원하실 때 말씀해주시면 바로 적용해드릴게요.

## ✅ 4단계: findol 브랜드 디자인 전면 적용

업로드해주신 디자인 시안(HTML)을 기준으로 화면을 전면 개편했어요.

- 헤더: findol 로고(돌 모양 아이콘) + 3개 탭(법령 검색/최신 개정/개정 이력)
- 히어로: 대형 검색창 + 빠른 검색 키워드 + 조약돌 마스코트 일러스트(SVG, 순수 코드로 직접 구현)
- 검색 결과: 카드형 그리드, 각 카드에 즐겨찾기(☆) 버튼 — 브라우저 localStorage에 저장
- 자주 찾는 법령: 클릭 시 실제 검색 실행 (가짜 데이터 아님)
- 최근 개정 법령: 지금까지 검색으로 쌓인 실제 타임라인 데이터에서 최신 4건 표시
- 검색창 옆 "통합검색/법률체계/고시·행정규칙" 선택 시 결과 범위 필터링
- 조문 본문을 보여주는 "법령 워크벤치"는 제외했어요 — 실제 조문 전문 데이터를 아직 API로 받아오지 않아서, 가짜 예시 조문을 넣는 대신 결과 카드 클릭 시 국가법령정보센터 원문으로 바로 연결되게 유지했습니다.

### 참고
- Pretendard 폰트는 CDN(jsdelivr)에서 불러옵니다. 이 폰트 로드가 실패해도 시스템 폰트로 자동 대체돼요.
- 즐겨찾기는 이 브라우저에만 저장돼요 (다른 기기/브라우저에서는 안 보여요).
